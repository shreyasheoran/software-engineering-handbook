## Scope

Name modules and user journeys covered and excluded.

## Unit and component tests

Cover pure logic, state transitions, validation and error handling.

## Integration tests

Cover boundaries, serialization, retries, timeouts, duplicates, pagination and partial failure.

## End-to-end tests

Exercise critical user journeys, including blocked and recovery paths.

## Accessibility checks

- Semantic structure and labels
- Keyboard-only operation
- Focus order, visibility and restoration
- Live-region behavior
- Contrast and zoom
- Manual assistive-technology review

## Performance tests

Name workload, duration, warm-up, repetitions, baseline and percentile or rate targets.

## Failure tests

Name injected outages, malformed data, bursts, slow consumers, crashes and replay.

## Browser/device matrix

List supported engines and representative viewport sizes.

## Evidence

Record commands, commit, date, environment and artifacts.
